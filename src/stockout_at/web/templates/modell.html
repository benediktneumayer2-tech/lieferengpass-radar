Modell und Prüfung

Ein Modell reiht Wirkstoffe nach dem Risiko einer neuen BASG-Meldung. Ob das trägt, entscheidet eine vorab festgelegte Prüfung.

Diese Seite zeigt, was das Modell im Rückblick leistet, wo es versagt und wie es geprüft wird. Die Schwächen stehen gleichberechtigt neben den Stärken.

Was vorhergesagt wird

Ein Fall ist ein Wirkstoff an einem Stichtag. Das Modell Z3 v0, eine regularisierte logistische Regression, schätzt für ihn die Wahrscheinlichkeit, dass binnen 4, 8 oder 12 Wochen eine neue BASG-Meldung beginnt oder erstmals erscheint. Der Hauptvergleich läuft über 8 Wochen gegen die einfache Stufenregel der Frühwarnliste.

Eine neue Meldung heißt nicht, dass ein Arzneimittel fehlt. Vorhersagen für einzelne Wirkstoffe erscheinen auf dieser Website nicht.

Reiht es besser als die einfache Regel?

Im Rückblick auf 2026 ja. Der Abstand ist in allen drei Maßen größer als null, das Intervall für die Trefferquote der 50 höchsten Wirkstoffe ist aber breit. Eine prospektive Prüfung ersetzt das nicht.

Was das Modell nicht kann

{% if f27_fakten %}

Das Modell reiht Wirkstoffe. Die Gesamtzahl neuer Meldungen sagt es nicht voraus.

Erwartet waren je Stichtag {{ f27_fakten.erwartet }} neue Meldungen, eingetroffen sind {{ f27_fakten.eingetroffen }}. Am {{ f27_fakten.erster.tag }} kamen {{ f27_fakten.erster.kam }} statt {{ f27_fakten.erster.erwartet }}, am {{ f27_fakten.tief.tag }} nur {{ f27_fakten.tief.kam }} statt {{ f27_fakten.tief.erwartet }}. Der Zusammenhang über {{ f27_fakten.stichtage }} Stichtage liegt bei {{ f27_fakten.korrelation }}: Stichtage mit höherer Erwartung brachten nicht mehr Meldungen. An {{ f27_fakten.ausserhalb }} von {{ f27_fakten.stichtage }} Stichtagen lag die Zahl außerhalb des 95-%-Zufallsbands; bei reinem Zufall wäre es etwa einer.

Für die Prüfung heißt das: Kommen in einer Zeit insgesamt mehr Meldungen, liegen die Punkte der Kalibrierung über der Diagonale, auch wenn die Reihung stimmt. Die Schwäche ist hier vor Beginn der Prüfung benannt. Das eingefrorene Modell wird deswegen nicht geändert.
